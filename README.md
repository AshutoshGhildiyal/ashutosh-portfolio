# Ashutosh — Personal Portfolio

A responsive dark-mode portfolio built with plain HTML, CSS, and JavaScript. No build step is required.

## Run locally

Open `index.html` in a browser. The detailed FinTech case study is available at `fintech-case-study.html`.

## Included files

- `index.html` — portfolio home page
- `styles.css` — visual system, responsive layout, and accessibility helpers
- `script.js` — navigation, architecture switcher, and project dialogs
- `fintech-case-study.html` — detailed FinTech project case study
- `Ashutosh-Resume.pdf` — resume linked from the header and contact section
- `case-study.css` — case-study-specific layouts

## Before publishing

- **Verify the GitHub repository URL.** The profile is linked to `https://github.com/AshutoshGhildiyal`; the FinTech repository link should only be used if that repository exists and is public.
- The homepage links to the supplied LinkedIn profile and resume PDF. Update `Ashutosh-Resume.pdf` whenever your resume changes.
- The email link uses the address supplied in the resume.
- Add your actual LeetCode profile URL when ready; the DSA section currently describes practice areas without linking to a generic homepage.
- Verify current project implementation against the repository. The case study labels Kafka, fraud detection, and other unconfirmed capabilities as planned or conceptual.
- The projects section and architecture selector are limited to the three backend projects listed in the supplied resume: Ride-Hailing, FinTech Transaction Processing, and Logistics & Delivery Tracking.
- Only add performance numbers, business impact, or scale claims that you can substantiate.

## Deploy

Upload all files together to GitHub Pages, Netlify, or another static host, preserving relative paths. No build step is required.
